# AWS deployment runbook

This is an operator runbook, not provisioned infrastructure. Validate the deployment in staging before serving public traffic.

1. Run CI, including the disposable pgvector database test. Build API and frontend images. The manual `release.yml` workflow publishes commit-SHA tags to GHCR; protect its `release` GitHub environment. For ECS, mirror approved images into private ECR and deploy immutable digests.
2. Create a private RDS PostgreSQL instance with a version supporting the vector extension; inspect `SHOW rds.extensions`. Enable encrypted storage, backups and point-in-time recovery. Apply `sql/001_init.sql` as a migration administrator. Grant a separate API role only CONNECT, schema USAGE and SELECT/INSERT/DELETE on chunks. Use a verified TLS connection string (`sslmode=verify-full` plus the RDS CA bundle mounted into the API container).
3. Run two ECS Fargate containers in the same task, or separate services with private service discovery. For the same-task layout change Nginx `proxy_pass` from `api:8000` to `127.0.0.1:8000` and rebuild. Expose only Nginx port 8080 to an ALB security group. Allow the API outbound PostgreSQL only to RDS and HTTPS egress for OpenAI. Do not expose port 8000 publicly.
4. Use an ALB HTTPS listener with ACM certificate and HTTP-to-HTTPS redirect. Keep Nginx request-size/rate limits and add AWS WAF/per-user quotas as needed. Configure health checks and readiness monitoring; investigate elevated 502/504 rates and database latency.
5. Store `OPENAI_API_KEY` and `DATABASE_URL` in Secrets Manager. Reference their ARNs in task-definition `secrets`, with least-privilege execution-role access. Set `APP_ENV=production`, `LLM_PROVIDER=openai`, `VECTOR_STORE=pgvector`, `AUTH_MODE=jwt`, `JWT_PUBLIC_KEY`, `JWT_ISSUER`, `JWT_AUDIENCE`, and exact `CORS_ORIGINS` for the deployed domain. Do not put secrets in image layers or frontend variables.
6. Configure your identity provider to issue RS256 tokens with tenant and role claims. Connect its browser login flow; the current UI accepts a token for portfolio demonstrations. Plan signing-key rotation: the current implementation pins a public key and needs rolling deployment on rotation.
7. Upload a small test document using an admin JWT, verify same-tenant citations, verify another tenant sees none, verify reader ingestion is denied, and check tool status. Run live model evaluation with a controlled budget. Review guardrail false positives and missed attacks using your own threat model.
8. Ship stdout to CloudWatch with redaction and retention policies. Alert on failures and latency, set OpenAI spending limits, load-test expected concurrency, and test RDS restoration. Roll back by deploying the prior image digest; avoid destructive schema changes that prevent rollback.

Secrets injected as environment variables are loaded at task startup. Rotate secrets and force a new ECS deployment to load new values. [AWS Secrets Manager in ECS](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/secrets-envvar-secrets-manager.html). Confirm extension compatibility for the selected RDS engine version. [RDS PostgreSQL extensions](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/PostgreSQL.Concepts.General.FeatureSupport.Extensions.html).
